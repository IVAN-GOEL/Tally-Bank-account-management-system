CODE EXAMPLE

Withdrawal rules by account

Account vs SavingsAccount vs CurrentAccount
Base: Account.java Standard Zero Floor 
public Transaction withdraw(double amount)
       throws BankException {
    if (this.balance - amount < 0) {
        throw new InsufficientFundsException(
            "Insufficient funds: Balance is ₹" + balance);
    }
    this.balance -= amount;
    return new Transaction("WITHDRAWAL", ...);
}

Baseline rule: standard accounts cannot drop below zero.

Override: SavingsAccount.java ₹1,000 Minimum Floor 
@Override
public Transaction withdraw(double amount)
       throws BankException {
    if (getCurrentMonthWithdrawalCount() >= 5) {
        throw new WithdrawalLimitExceededException();
    }
    if (this.balance - amount < 1000.0) {
        throw new MinimumBalanceException(
            "Must retain minimum ₹1,000");
    }
    this.balance -= amount;
    return new Transaction("WITHDRAWAL", ...);
}

Enforces both 5 withdrawals/month limit and ₹1,000 minimum balance.

Override: CurrentAccount.java ₹10,000 Overdraft 
@Override
public Transaction withdraw(double amount)
       throws BankException {
    double minAllowed = -10000.00; // Overdraft
    if (this.balance - amount < minAllowed) {
        throw new InsufficientFundsException(
            "Overdraft limit breached: max ₹10K");
    }
    this.balance -= amount;
    return new Transaction("WITHDRAWAL", ...);
}

Permits negative balances down to -₹10,000 for business liquidity.

Custom exceptions

java.lang.Exception
Exception (Java standard library base)
└── BankException extends Exception (Domain base exception)
├── InsufficientFundsException

Thrown when balance or overdraft limit is breached.

├── MinimumBalanceException

Thrown when savings balance drops below ₹1,000.

├── WithdrawalLimitExceededException

Thrown when savings withdrawals exceed 5 per month.

└── InvalidAmountException

Thrown when transaction amount is less than or equal to ₹0.
